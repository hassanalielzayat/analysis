## 📋 نبذة عن المشروع

- ✅ تحليل **٥ منافسين رئيسيين** و**٤ منافسين إضافيين**
- ✅ مقارنة **التقييمات والمراجعات** (بيانات بصرية)
- ✅ جدول **مقارنة الأسعار التقديرية**
- ✅ **خريطة التوزيع الجغرافي** للصالونات
